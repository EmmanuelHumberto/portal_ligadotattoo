# AR-33 Visual System

Direction:
- near-black base rather than pure black everywhere;
- layered graphite surfaces;
- thin low-contrast borders;
- restrained warm-gold accent for calls to action and trust markers;
- product imagery carries visual drama;
- cards communicate density without becoming dashboard clutter;
- typography uses large editorial headlines and compact technical metadata.

Retention mechanics are informational rather than manipulative: useful cross-links,
related products, editorial modules, price freshness, provenance and clear next
actions. No infinite-scroll dark patterns are required.

Accessibility:
- visible focus states;
- minimum 44px primary controls;
- text/background contrast target WCAG AA;
- semantic headings/nav/main;
- reduced-motion implementation required for production animations;
- images require meaningful alt when informative.
