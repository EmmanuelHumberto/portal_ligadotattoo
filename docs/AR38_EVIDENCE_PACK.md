# AR-38 Release Candidate Evidence Pack

Required evidence directory per release:
- release-candidate.json;
- immutable image digest verification;
- lint/typecheck/build results;
- unit/integration/contract results;
- migration verification/rehearsal;
- Playwright public/Admin E2E report;
- smoke results;
- security regression report;
- dependency/container scans;
- load/performance report;
- Core Web Vitals lab/field snapshot where available;
- accessibility verification;
- backup/restore exercise reference;
- observability dashboard/alert verification;
- provider fallback evidence;
- ingestion-to-public evidence;
- media rights/takedown evidence;
- rollback rehearsal/reference;
- final signed/recorded decision.

Absence of evidence is not equivalent to a passing test.
