# Final Non-Negotiable Invariants

1. Source data is evidence, not automatic canonical truth.
2. AI output cannot self-promote to canonical/public authority.
3. OpenAI/Anthropic/DeepSeek/future provider credentials are backend-only.
4. AI provider routing/fallback is configuration/workload-driven.
5. Dynamic server-side URL fetches pass through SSRF-safe infrastructure.
6. Public DTOs expose governed projections, not raw persistence models.
7. Media rights state controls public eligibility and can revoke it.
8. Private affiliate parameters remain server-side.
9. Privileged actions require capabilities and appropriate audit.
10. Async handlers are idempotent, bounded and observable.
11. Production artifacts are immutable and promoted from staging by digest.
12. Schema rollout preserves rollback compatibility through expand/contract.
13. Analytics remains first-party, allowlisted and non-invasive.
14. Growth experiments cannot waive security, rights, provenance or integrity.
15. Release readiness is evidence-based.
