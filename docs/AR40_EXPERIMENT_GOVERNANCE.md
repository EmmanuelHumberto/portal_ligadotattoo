# Experiment Governance

Every experiment requires:
- owner;
- hypothesis;
- primary metric;
- guardrail metrics;
- variants and allocation;
- start/stop criteria;
- review for security/privacy/editorial/rights impact.

Experiments may optimize:
- discovery composition;
- card information hierarchy;
- search ranking presentation;
- navigation labels;
- content recommendation layout.

Experiments must not:
- fabricate scarcity;
- obscure affiliate/commercial context;
- weaken provenance;
- bypass rights;
- manipulate canonical facts;
- reduce security controls;
- use deceptive consent patterns.

Assignment is deterministic per experiment + anonymous session. Exposure must be
recorded before attributing outcome.
