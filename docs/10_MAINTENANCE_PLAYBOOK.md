# Maintenance Playbook

When adding an AI provider:
- implement provider adapter;
- normalize errors/results;
- add registry/config schema;
- add workload-routing tests;
- add outage/fallback scenario;
- verify secret redaction.

When adding a new source:
- classify trust/risk;
- use safe fetch;
- preserve evidence;
- define parser/version;
- add idempotency;
- never grant automatic canonical authority.

When adding a new public entity:
- define canonical model;
- define public projection;
- define SEO/indexability;
- define media rights relationship;
- define search representation;
- define Admin capability/audit path;
- define analytics allowlist fields.

When changing visual components:
- preserve dark premium design language;
- preserve accessibility/focus/contrast;
- test responsive behavior;
- watch JS/image/performance budgets;
- prefer useful information hierarchy over decorative density.
