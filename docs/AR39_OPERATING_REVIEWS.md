# Operating Reviews

## Daily during stabilization
Review:
- availability/error/latency;
- top application errors;
- job/outbox age and dead letters;
- ingestion freshness/failures;
- AI provider distribution, fallback, latency and cost;
- media rights expiry/takedown;
- commerce freshness/redirect errors;
- security alerts;
- Web Vitals;
- open incidents.

## Weekly after stabilization
Add:
- SLO/error-budget trend;
- capacity trend;
- dependency/provider reliability;
- recurring incident patterns;
- content/data quality exceptions;
- backup/restore status;
- dependency/security findings;
- performance regressions;
- prioritized reliability backlog.
