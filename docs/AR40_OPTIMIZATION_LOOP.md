# Continuous Optimization Loop

Weekly:
1. review user-value and quality KPIs;
2. identify largest friction/opportunity;
3. inspect underlying qualitative/data evidence;
4. choose content, data, UX or technical intervention;
5. define expected outcome and guardrails;
6. deploy normally or through an approved experiment;
7. observe sufficient evidence;
8. keep, iterate or revert;
9. record decision.

Priority favors changes that improve trustworthy task completion, discovery
quality, technical clarity and portal reliability rather than superficial click
maximization.
