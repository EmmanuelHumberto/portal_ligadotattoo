# AR-34 Decisions

1. Search autocomplete begins after two characters with debounce.
2. Suggestions are capped to eight.
3. Filter state is shareable through the URL.
4. New filters reset cursor pagination.
5. Comparison supports at most four machines.
6. Favorites/recent history remain local by default.
7. Analytics uses an allowlist and excludes raw query strings.
8. Galleries are progressively enhanced client components.
9. Initial catalog/search pages remain server rendered.
10. Client query caching is short-lived and non-authoritative.
11. Comparison tables prioritize technical differences over marketing prose.
12. Mobile catalog filters collapse into the main flow.
