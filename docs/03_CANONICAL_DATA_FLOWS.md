# Canonical Data Flows

## Product fact acquisition
Source -> Safe Fetch -> Observation/Evidence -> Claim/Proposal -> Review ->
Canonical Fact -> Public Projection -> Search/Web.

Forbidden shortcut:
Source/AI -> Canonical Fact.

## AI enrichment
Application workload -> AI Provider Hub -> configured routing -> provider ->
normalized response -> execution metadata -> proposal/assistive result.

Provider keys exist only in backend runtime secret resolution.

## Media
Acquire/upload -> validate -> original object -> rights/review ->
variants -> public eligibility -> CDN/public projection.

TAKEDOWN/EXPIRED/RESTRICTED overrides cache and presentation.

## Commerce
Seller/listing acquisition -> normalized listing -> price observation ->
freshness/eligibility -> public offer -> server-side redirect -> destination.

## Editorial
Draft -> review -> publish -> public projection -> SEO/Search/Web.

## Analytics
Allowlisted browser event -> first-party ingest -> aggregate/projection ->
Admin intelligence -> optimization decision.
