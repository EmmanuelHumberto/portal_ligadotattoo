# AR-33 Decisions

1. Premium dark is the default portal identity.
2. Gold is an accent, not a full-surface theme color.
3. Product cards prioritize machine image, brand/type and actionable offer state.
4. Provenance is visible near technical product information.
5. Editorial and commerce remain visually distinct but share the card system.
6. Navigation exposes Máquinas, Marcas, Notícias, Blog Técnico, Eventos and Ofertas.
7. Search is globally available.
8. Admin uses the same tokens but higher information density.
9. Responsive layouts collapse rather than horizontally overflow core content.
10. Loading/error/empty states are part of the visual system.
11. Server-rendered public pages preserve SEO and initial performance.
12. Engagement is driven by useful discovery, not coercive interaction patterns.
