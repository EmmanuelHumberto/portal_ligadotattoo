# Frontend Architecture

Visual direction:
- premium dark interface;
- near-black backgrounds and graphite surfaces;
- restrained gold accents;
- strong editorial hierarchy;
- information-rich cards;
- product imagery as a primary visual anchor;
- Admin shares identity but uses higher information density.

Public runtime:
- server-rendered canonical entry surfaces;
- progressive enhancement for search/filter/compare/gallery;
- URL-driven filter state;
- short-lived client cache;
- local-device favorites/recent history baseline;
- first-party bounded analytics.

Core public surfaces:
Home, Discovery, Machines, Product Detail, Brands, Search, Compare, Offers,
Editorial, Events.

Admin surfaces:
operations, catalog, knowledge/proposals, sources/ingestion, AI executions,
media/rights, editorial, commerce, audit and analytics.

Engagement is optimized through usefulness and discovery, not deceptive or
compulsive interaction patterns.
