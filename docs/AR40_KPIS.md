# Product Intelligence KPIs

User value:
- product detail engagement;
- successful search result-open rate;
- zero-result search rate;
- compare completion;
- useful offer-open rate;
- editorial completion/related navigation.

Data/product quality:
- products with core specifications;
- products with public media;
- products with provenance;
- products with fresh offers;
- source freshness;
- unresolved canonical proposals.

Experience:
- LCP / INP / CLS;
- HTTP error rate;
- search latency;
- empty/error-state frequency.

Do not interpret raw time-on-site as inherently positive. Longer sessions caused
by poor navigation are not a success signal.
