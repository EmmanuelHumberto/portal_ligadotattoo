# AR-34 — Frontend Interaction, Search, Compare & Discovery Runtime

Incremental pack over AR-33.

Implements:
- global autocomplete;
- advanced machine filters synchronized with URL state;
- cursor pagination;
- machine comparison workspace;
- privacy-safe favorites and recently viewed;
- interactive media gallery;
- related-content discovery rail;
- lightweight client query cache;
- analytics boundary with allowlisted events and no raw search text by default.

The interaction layer preserves server-rendered entry pages and progressively
enhances discovery in the browser.
