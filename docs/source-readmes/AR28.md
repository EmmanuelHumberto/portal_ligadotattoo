# AR-28 — Source Registry, Secure Ingestion & Story Discovery

Incremental implementation pack over AR-27.

Implements:
- source registry and crawl targets;
- explicit compliance/robots policy metadata;
- SSRF-safe HTTP acquisition boundary;
- immutable source snapshots;
- content hashing and deduplication;
- ingestion run observability;
- extraction jobs;
- editorial story-candidate discovery;
- product/manufacturer discovery candidates;
- Admin read APIs for sources and ingestion runs.

Security rule: ingestion never performs arbitrary outbound requests from user-supplied URLs. Targets must belong to an enabled registered source and pass URL/IP policy checks.
