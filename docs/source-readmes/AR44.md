# AR-44 — Staging-Ready Distribution

Penultimate formulation artifact.

AR-44 packages the integrated baseline as an operational staging distribution:
- environment/secrets contract;
- staging Compose topology;
- immutable Web/API/Worker image contract;
- migration + bootstrap jobs;
- AI Provider Hub staging configuration;
- health/readiness and smoke commands;
- seed policy;
- deployment and rollback scripts;
- staging acceptance checklist;
- handoff structure for AR-45 Final Acceptance & Master Release.

No production secret is included. Staging must use isolated credentials and
provider accounts/keys.
