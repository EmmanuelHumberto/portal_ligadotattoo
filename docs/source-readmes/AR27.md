# AR-27 — Editorial Automation & Human Curation Executable Slice

Incremental implementation pack over AR-26.

Implements:
Source/Story Candidate -> AI-assisted Draft -> Human Review -> Approval
-> Scheduled/Direct Publication -> Public News/Blog/Event API -> Search/Cache projection

Core policy:
- AI may discover, classify, summarize and draft.
- AI output is always editable.
- Human review is the baseline publication authority.
- Direct publication is only possible through an explicit policy gate and remains auditable.
- Editorial content never promotes technical claims into canonical facts.
