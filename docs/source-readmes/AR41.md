# AR-41 — Final Architecture Consolidation & Technical Handbook

Consolidation of AR-01 through AR-40.

This handbook is the engineering map for the Portal Tattoo platform. It does not
replace the detailed artifacts; it defines how the major subsystems fit together,
where authority lives, which boundaries must not be bypassed, and how engineers
should evolve the platform safely.

Core architectural principles:
- public presentation consumes governed public projections;
- acquired/source data is evidence, not automatic truth;
- AI providers are interchangeable through a backend-only Provider Hub;
- AI output never self-promotes into canonical authority;
- media publication depends on current rights eligibility;
- commerce destinations and private parameters remain backend-side;
- privileged operations are capability-gated and audited;
- asynchronous work is idempotent, observable and recoverable;
- production promotes immutable artifacts verified in staging;
- analytics optimizes user value without invasive tracking.
