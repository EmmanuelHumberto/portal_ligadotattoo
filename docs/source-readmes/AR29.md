# AR-29 — AI Provider Hub Runtime & Policy Engine

Incremental implementation over AR-28.

Implements the provider-neutral AI runtime:
- provider/model registry;
- workload policies and ordered routes;
- OpenAI, Anthropic and DeepSeek HTTP adapters;
- fallback chains;
- timeout/retry/circuit-breaker runtime;
- budget and token limits;
- structured JSON output validation boundary;
- backend-only secret resolution;
- execution observability;
- Admin read APIs for providers/models/policies/executions.

No provider API key is returned by any Admin or public endpoint.
