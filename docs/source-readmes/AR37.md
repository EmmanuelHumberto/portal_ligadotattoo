# AR-37 — Deployment, Environments, CI/CD & Release Engineering

Incremental pack over AR-36.

Implements:
- DEV / STAGING / PROD environment topology;
- immutable Web/API/Worker artifacts;
- CI quality/security gates;
- migration job and expand/contract database policy;
- artifact promotion by image digest;
- rolling deployment with readiness gates;
- automated smoke verification;
- rollback procedures;
- PostgreSQL backup/restore runbook;
- observability wiring and SLO baseline;
- bootstrap/seed boundary;
- release manifest and production launch checklist.

Provider credentials, storage credentials and database secrets remain runtime-only.
No secret is baked into Web/API/Worker images.
