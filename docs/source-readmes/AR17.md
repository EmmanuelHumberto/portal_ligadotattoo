# AR-17 — Complete Executable PostgreSQL Migration Pack

Executable PostgreSQL baseline for Portal Tattoo.

It covers M00–M15: schemas/extensions, operations/audit, IAM, catalog, media, knowledge,
sources, ingestion, technical service, laboratory, commerce/price history, editorial/blog/news/events,
AI Provider Hub, PostgreSQL search, imports and cross-schema hardening.

Apply migration files in lexical order, then seeds, then verification:

```bash
for f in database/migrations/*.sql; do psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f "$f"; done
for f in database/seeds/*.sql; do psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f "$f"; done
for f in database/verify/*.sql; do psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f "$f"; done
```

AI provider seeds contain metadata only. No API keys are stored.
