# AR-31 — Media Library, Rights Governance & Delivery Pipeline

Incremental pack over AR-30.

Implements:
- Admin media library read API;
- media lifecycle and review queue;
- rights/license records and expiry;
- upload/ingestion origin metadata;
- image variant projection;
- storage/delivery abstraction;
- safe public media DTO;
- rights-expiry worker;
- cache invalidation;
- audit/outbox events.

Public media remains gated by ACTIVE + PERMITTED rights.
