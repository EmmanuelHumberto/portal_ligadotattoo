# AR-35 — SEO, Structured Data, Performance & Web Vitals Hardening

Incremental pack over AR-34.

Implements:
- canonical metadata and Open Graph baseline;
- robots and sitemap endpoints;
- Product, Article and Event JSON-LD builders;
- SEO-safe filtered/search route policy;
- image delivery/component policy;
- font loading baseline;
- route cache/revalidation matrix;
- Web Vitals first-party reporting boundary;
- performance budgets;
- accessibility and release verification checklist.

Structured data only represents data already eligible for public display.
