# AR-24 — IAM, Authorization, Worker Runtime & Catalog Completion

Incremental implementation pack over AR-23.

Implements:
- JWT/OIDC-oriented authentication boundary;
- ActorContext and capability guard;
- persistent audit repository;
- outbox dispatcher;
- job worker reservation/retry/dead-letter runtime;
- Manufacturer update/status with optimistic concurrency;
- ProductModel aggregate/repository/commands;
- Catalog read endpoints;
- SQL migration additions;
- test inventory.

Important: JWT signature verification must be wired to the deployment OIDC issuer/JWKS configuration before production exposure.
