# AR-36 — Security Hardening, Abuse Controls & Production Boundary Review

Incremental pack over AR-35.

Implements production-oriented security boundaries:
- CSP and security headers;
- origin/CSRF guard for cookie-authenticated mutations;
- hardened session cookie policy;
- rate-limit policy by endpoint class;
- bot/abuse signals without invasive fingerprinting;
- upload MIME/size/signature validation boundary;
- SSRF regression policy for all server-side URL fetches;
- public quotas;
- secret rotation/reference policy;
- dependency/container baseline;
- threat model and production security gate.

This pack is defense-in-depth. Infrastructure controls remain required.
