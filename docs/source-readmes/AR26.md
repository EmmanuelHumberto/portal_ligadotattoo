# AR-26 — Knowledge Canonicalization Executable Slice

Incremental implementation pack over AR-25.

Implements the canonical knowledge workflow:

Evidence -> Claim -> Conflict detection -> Canonical Proposal -> Human Decision
-> Immutable Canonical Fact History -> Audit/Outbox -> Public projection invalidation

Core rule: AI, ingestion and external sources may produce evidence and claims, but only an authorized human decision may promote a value into canonical public knowledge.
