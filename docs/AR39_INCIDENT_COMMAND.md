# Incident Command

For SEV-1/SEV-2 assign:
- Incident Commander: owns decisions/priorities.
- Operations Lead: executes technical containment/recovery.
- Communications Lead: maintains internal/external status communication.
- Scribe: timestamps actions, observations and decisions.
- Subject Matter Owners: join as required (security, data, AI, ingestion, media).

Rules:
1. One Incident Commander at a time.
2. Separate facts from hypotheses.
3. Prefer reversible containment.
4. Do not paste secrets into incident channels/tickets.
5. Preserve correlation IDs, audit references and release IDs.
6. Record every production mutation made during response.
7. Define explicit exit criteria before resolving.
