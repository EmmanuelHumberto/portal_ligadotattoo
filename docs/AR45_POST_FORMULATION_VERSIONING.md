# Post-Formulation Versioning

The AR sequence ends at AR-45.

Future work moves to normal product lifecycle:

v0.x
Integrated engineering/staging candidates while closing execution findings.

v1.0
First production release after final GO.

v1.x
Backward-compatible features, UX improvements, provider additions, content/data
improvements and operational hardening.

v2.x
Material product/platform changes that justify a major release.

Architecture Decision Records (ADRs) should be used for significant future
technical decisions rather than extending the AR formulation numbering.

Examples:
- ADR-001 Add a new AI provider.
- ADR-002 Change queue infrastructure.
- ADR-003 Introduce account-based personalization.
