# AR-39 Decisions

1. SEV-1/SEV-2 use explicit incident command.
2. Security/integrity can override impact-based severity estimates.
3. Error budget controls release risk but never waives security/rights/integrity.
4. AI provider outages degrade AI workflows, not canonical governance.
5. Queue recovery requires idempotency understanding before requeue.
6. Media takedown is a priority operational path with cache/CDN verification.
7. Credential incidents require revoke/rotation independently of rollback.
8. Rollback is application recovery, not universal incident remediation.
9. Initial launch uses a 72-hour heightened stabilization baseline.
10. Daily reviews during stabilization become weekly reliability reviews afterward.
11. Incident actions preserve audit/evidence.
12. Postmortems produce owned, verifiable corrective actions.
