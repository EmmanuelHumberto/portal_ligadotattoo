# AR-35 SEO Policy

Canonical indexable surfaces are public category, product, brand, editorial and
event pages. Search results, comparison workspaces, Admin and arbitrary filtered
combinations are not canonical landing pages.

Structured data is generated only from publicly eligible application data. It
does not introduce claims that are absent from the canonical/public projection.

Product offers may appear in JSON-LD only while the public commerce endpoint
considers them fresh and eligible. Restricted/expired media must not be included
as Product/Article/Event images.

Sitemap generation consumes dedicated public SEO projections so private drafts,
review candidates and disabled entities are excluded upstream.

Canonical URLs strip interaction/filter state unless a curated landing page is
explicitly created.
