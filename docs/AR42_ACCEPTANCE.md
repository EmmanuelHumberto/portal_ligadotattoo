# AR-42 Acceptance

AR-42 is accepted when:
- a single repository topology exists;
- package/workspace ownership is explicit;
- Web/API/Worker have concrete entrypoints;
- runtime configuration is centralized;
- local infrastructure is declared;
- ordered migration runner exists;
- AI Provider Hub schema baseline exists;
- bootstrap procedure is documented;
- known integration conflicts are explicitly registered.

AR-42 does not claim full compile/runtime verification of every historical module.
That is the explicit purpose of AR-43.
