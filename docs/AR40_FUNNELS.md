# AR-40 Funnel Definitions

Discovery:
session -> product_open -> compare_complete -> offer_open.

Search:
search_submit -> search_result_open -> product_open.

Editorial:
editorial_open -> editorial_complete -> related product/content navigation.

These are diagnostic funnels, not mandates to maximize every downstream click.
For example, a user finding a technical answer without opening an offer can still
represent a successful portal outcome.

Primary metrics should be paired with quality guardrails such as zero-result rate,
data provenance coverage, page performance and error rate.
