# AR-41 Decisions

1. AR-41 is the consolidated technical navigation layer for AR-01..AR-40.
2. Canonical authority, evidence and public projection remain distinct concepts.
3. The AI Provider Hub is a stable platform boundary, not a vendor-specific feature.
4. OpenAI, Anthropic and DeepSeek are adapters behind configurable workload routing.
5. Frontend design and backend governance are intentionally decoupled.
6. Public experience remains sophisticated while privileged Admin favors density.
7. Security, rights and data integrity override growth/experimentation objectives.
8. Deployment and operations are part of architecture, not post-development add-ons.
9. Architecture invariants are regression requirements for future development.
10. New modules must declare ownership, authority, trust boundaries and public projection.
11. Documentation must evolve with contracts and critical operational procedures.
12. The next phase should move from architecture artifacts to an integrated executable baseline and staged verification.
