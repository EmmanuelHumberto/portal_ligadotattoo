# AR-35 Test Matrix

Metadata:
- canonical absolute URL;
- noindex filtered catalog;
- product title/description/image;
- OG/Twitter fields.

Robots/sitemap:
- Admin/API/search/compare excluded;
- only public eligible entities in sitemap;
- static canonical routes present.

Structured data:
- valid Product;
- only fresh public offers;
- Article vs NewsArticle;
- Event dates/location;
- restricted media absent upstream;
- `<` escaped in JSON-LD script.

Performance:
- image dimensions/sizes;
- lazy noncritical images;
- no third-party sync scripts;
- field vitals allowlist;
- route cache matrix honored.

Accessibility:
- keyboard/focus;
- labels;
- contrast;
- 200% zoom;
- reduced motion;
- touch targets.
